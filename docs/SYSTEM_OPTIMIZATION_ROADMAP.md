# 系統優化項目總覽（第一份）

> 產出日期：2026-07-02
> 分析範圍：全站約 50 個頁面、70 組 API 路由、90 個 Prisma 資料模型
> 本文件為優化系列文件的第一份，盤點四大面向的可優化項目；後續可依優先級拆出各面向的細部實施文件。

## 優先級定義

| 級別 | 定義 |
|------|------|
| P0 | 影響核心功能（打卡）、資安合規、資料安全，應立即處理 |
| P1 | 影響日常申請/審核流程效率，近期處理 |
| P2 | 體驗與效率增強，中期處理 |
| P3 | 長期改進（i18n、離線、無障礙等） |

## 執行摘要

系統基礎架構完整（考勤、排班、請假、加班、薪資、獎金、審核流、財產管理、通知、安全機制皆已建置），主要優化空間集中在四類：

1. **員工端體驗**：打卡流程摩擦點（GPS/WiFi/防疫問卷提示）、缺通知中心、導覽選單過長無分組、表單缺草稿與統一驗證。
2. **管理端體驗**：批次操作與預覽不足、多處 `limit=1000` 全量載入員工、缺統計圖表與高級篩選、缺操作稽核呈現、system-monitoring 近乎空殼。
3. **系統功能**：無備份還原機制、無資料保留政策、健康檢查僅涵蓋 DB、Cron 任務無統一管理、多個已定義通知事件未整合。
4. **系統設定**：39 個設定路由但「設定變更無稽核日誌」、無匯出/匯入/回滾、通知設定架構混亂、多處 hard-coded 常數應設定化。

合計約 **80+ 項**可優化項目，其中 P0 級 10 項。
