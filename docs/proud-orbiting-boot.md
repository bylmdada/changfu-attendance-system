# 重設計:財產管理設定 —「維護／審核人員指派」拆成上下兩區塊

## Context
[system-settings/property-management/page.tsx](../src/app/system-settings/property-management/page.tsx) 的「維護／審核人員指派」卡(原 532–756 行)把太多功能擠在一起,最雜的是新增列:帳號輸入 ＋ **新增角色** select ＋ **清單角色篩選** select ＋ 新增/更新按鈕並排,且整卡有三個外觀相同、語意不同的角色下拉。目標:拆成「① 新增指派」「② 現有指派清單」兩個清楚區塊,降低視覺與操作混淆。**純前端版面/互動重組,API 與資料邏輯不動。**

> 狀態:已實作完成(ESLint 通過)。本檔保留為設計/實作紀錄。

## 具體變更(皆在 page.tsx)
1. **拆兩張卡**:把原單卡拆成兩個 `bg-white rounded-xl …` 區塊,標題分別「① 新增指派」「② 現有指派清單」。
2. **新增列只留三件**:移除其中的「清單角色篩選」select;按鈕固定為「新增」,拿掉雙關的 `selectedAssignment ? '更新角色' : '新增'`。選到已指派候選人時「新增」按鈕 disabled。
3. **角色篩選搬到 ②**:把 `assignmentRoleFilter` 的 select 移到指派清單上方,與「顯示 X/Y、清除篩選」合併成一條工具列。
4. **統計 chips 移到 ② 頂部**。
5. **改角色單一入口**:角色變更只保留逐列「儲存」(`saveAssignmentRole`)。選到「已指派」的候選人時提示「此員工已在下方清單,請於清單調整角色」,取代原本用新增列改角色的路徑。
